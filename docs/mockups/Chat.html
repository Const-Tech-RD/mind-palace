I want to get back into fingerstyle guitar. Can you give me a 20-minute daily practice plan? I keep stalling on Travis picking.
6:02 PM

Here is a 20-minute plan built around fixing Travis picking first, since everything else in fingerstyle leans on a steady thumb.

  1. Thumb only, 5 min. Alternate bass between strings 6 and 4 on a C chord, metronome at 60. Don’t speed up until it feels boring.
  2. Add one finger, 5 min. Index on string 3 between thumb notes. Keep the thumb exactly as it was.
  3. Full pattern, 7 min. Add middle on string 2. Loop C to G, slowly.
  4. Record 1 minute, 3 min. Listen back for an uneven thumb, the usual reason it stalls.

Move the metronome up 4 bpm only after two clean days in a row.
